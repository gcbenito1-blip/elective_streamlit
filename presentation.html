🔍 Step 1: Scraping & Cleaning

  • Scrape reviews using google-play-scraper
  • Language detection (Tagalog vs English)
  • Text cleaning: URLs, mentions, hashtags
  • Remove emojis and special symbols
  • Unicode normalization & lowercasing

🌐 Step 2: Translation

  • Batch translate Tagalog reviews
  • Combine with English reviews
  • Sort by chronological order
  • Parse dates to datetime format
  • Export: final_dataset.csv (41,287 reviews)

App-Level Text Processing

Streamlit Application Processing (elective.py & eTab*.py)

1️⃣ Date Filtering

Sidebar date range picker filters dataset by at column

2️⃣ Stopword Removal

NLTK English stopwords + custom app-specific stopwords

app, update, version, phone, po, opo, ng, etc.

3️⃣ Token Filtering

Keep tokens with length > 1

4️⃣ Direct Usage

translated column used for:

  • Sentiment analysis (VADER)
  • Topic modeling (NMF)

Sentiment Analysis (VADER)

💭 VADER: Valence Aware Dictionary and sEntiment Reasoner

Rule-based sentiment analysis tuned for social media text

😊 Positive

Score ≥ 0.05

Happy, satisfied users

😐 Neutral

-0.05 to 0.05

Mixed or factual reviews

😞 Negative

Score ≤ -0.05

Complaints, issues, bugs

📊 Analysis Outputs

  • Sentiment distribution (pie/bar chart)
  • Score histogram
  • Negative review topic analysis
  • AI-generated topic labels for negative feedback
